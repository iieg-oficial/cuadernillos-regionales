\section*{Descripción general}

El municipio de << dg_nombre >> se localiza en la región << dg_region >> del estado de Jalisco. Sus municipios colindantes son << dg_colindantes >> (ver \mapref{map:base}). Tiene una extensión territorial de << dg_area_km2 >> kilómetros cuadrados.

Su cabecera municipal se localiza en las coordenadas << dg_lat >> latitud norte y << dg_lon >> longitud oeste, a una altura de << dg_elev1 >> metros sobre el nivel del mar (msnm). El territorio municipal presenta altitudes entre << dg_elevmin >> y << dg_elevmax >> msnm, con predominio de pendientes << dg_pendiente_predom >>.

La mayor parte del municipio presenta un clima << dg_clima_predom >>. La temperatura media anual es de << dg_temp_media >>~°C, y la precipitación acumulada anual promedio es de << dg_prec_acum >> mm.

El viento dominante tiene una dirección proveniente del << dg_viento_predom >> y una frecuencia anual de << dg_viento_predom_fr >> \% en el municipio.

El municipio está constituido predominantemente por la unidad geológica << dg_geo_predom >>. Los suelos dominantes corresponden a << dg_edaf_predom >> (ver \tabref{tab:sintesis}).
